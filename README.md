# 운명人지도

성향 · 사주 · 타로를 중심으로 한 Expo(React Native) 앱.

- 표시명: **운명人지도** (가운데 사람人)
- 슬러그: `unmyeong-injido`
- **별칭:** 인생인지도 · 운명인지도 (같은 앱, 별도 프로젝트 아님)
- 경로: `/Volumes/Netac 2TB/Dev/Expo/unmyeong-injido`  
  (편의 링크: `~/Projects/unmyeong-injido`)

## 핵심

1. **홈** — 신분증(ID 카드) + 오늘의 **종합 운세**
2. **성향 / 사주 / 타로 / 관상** — 하단 탭별 디테일 영역
3. **신분증** — 이름·생년월일·성별·혈액형·MBTI·별자리 입력 (탭하여 수정)

> 중복본 **역술함**(`yeoksulham`)은 본편이 아닙니다. 2026-08-30 작업 폴더에서 제거하고 `_archive/yeoksulham`에만 남겼습니다. Cursor는 `~/Projects/unmyeong-injido`로만 여세요.
