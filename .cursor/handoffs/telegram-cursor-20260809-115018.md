**입력 후** — 기존 신분증 + 종합 운세 화면 유지

`npm start` 후 앱 데이터 없이 열면 빈 화면이 보입니다. (이전에 입력한 프로필이 있으면 AsyncStorage 때문에 바로 운세 화면이 뜰 수 있어요.)
