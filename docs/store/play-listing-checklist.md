## 2. 스토어 문구 초안

### 짧은 설명 (80자 이내)

> 성향·사주·타로·지인 궁합으로 오늘을 짚어 보는 참고용 운세 앱

### 긴 설명

```
운명人지도는 성향·사주·타로·지인 궁합을 한곳에서 살펴보는 엔터테인먼트 앱입니다.

• 지도 — 오늘의 종합 운세와 키워드
• 성향 — 별자리·띠·MBTI 등 조합과 오늘의 성향
• 사주 — 나의 사주와 오늘·주·월·년 기운
• 타로 — 오늘의 카드와 한 점 타로
• 지인 — 만세력 기반 궁합과 오늘 해보기

프로필·지인·기록은 기기 안에만 저장되며, 비밀번호로 암호화한 백업·복구를 지원합니다.

본 앱의 모든 해석은 오락·참고용이며, 의학적·법률적·재정적 조언을 대체하지 않습니다.
```

### 콘텐츠 등급

- 카테고리: **엔터테인먼트** (또는 Lifestyle)
- 운세·점술·자기성찰 앱으로 신고
- 폭력·성적 콘텐츠 없음 기준으로 설문 작성

## 7. Play Console — 앱 만들기 · 테스트 트랙

계정 설정이 끝나기 전에도 **앱 레코드·스토어 등록정보·설문**은 미리 채울 수 있습니다.

### 7-1. 앱 만들기

1. Play Console → **모든 앱** → **앱 만들기**
2. 앱 이름 `운명人지도` · 기본 언어 **한국어** · 앱 · **무료**
3. 선언(스팸·정책) 체크 후 만들기
4. **앱 콘텐츠** → **개인정보처리방침** URL  
   `https://firstking4.github.io/unmyeong/legal/privacy.html`
5. **스토어 설정** → **스토어 등록정보** — §2 문구·§3 그래픽·고객지원 `firstking4@gmail.com`

### 7-2. AAB 업로드 (내부 테스트 먼저)

1. **테스트 → 내부 테스트** → **새 버전 만들기**
2. §5 AAB 업로드 (또는 새 `npm run build:android:aab`)
3. 출시 노트 예: `0.1.3 — Play 출시 준비 첫 빌드`
4. 검토 후 **내부 테스트에 출시**

### 7-3. 개인 계정 — 비공개 테스트 (출시 전 필수)

| 요건 | 내용 |
|---|---|
| 기간 | 비공개 테스트 **14일** 이상 |
| 테스터 | **12~20명** (이메일 초대 또는 Google 그룹) |
| 순서 | 내부 테스트 스모크 후 → 비공개 테스트 트랙에 동일 AAB |

지금부터 테스터 이메일을 모아 두면, 계정 설정이 끝나자마자 비공개 테스트로 넘어갈 수 있습니다.
