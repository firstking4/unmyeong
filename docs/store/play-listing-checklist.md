## 2. 스토어 문구 초안

### 짧은 설명 (80자 이내)

> 성향·사주·타로·지인 궁합으로 오늘을 짚어 보는 참고용 운세 앱

### 긴 설명

```
운명人지도는 성향·사주·타로·지인 궁합을 한곳에서 살펴보는 엔터테인먼트 앱입니다.

• 지도 — 오늘의 종합 운세와 키워드
• 성향 — 별자리·띠·MBTI 등 조합과 오늘의 성향
• 사주 — 나의 사주와 오늘·주·월·년 기운
• 타로 — 오늘의 카드와 질문 스프레드
• 지인 — 만세력 기반 궁합과 오늘 해보기

프로필·지인·기록은 기기 안에만 저장되며, 비밀번호로 암호화한 백업·복구를 지원합니다.

본 앱의 모든 해석은 오락·참고용이며, 의학적·법률적·재정적 조언을 대체하지 않습니다.
```

### 콘텐츠 등급

- 카테고리: **엔터테인먼트** (또는 Lifestyle)
- 운세·점술·자기성찰 앱으로 신고
- 폭력·성적 콘텐츠 없음 기준으로 설문 작성

## 3. 그래픽 자산

| 자산 | 권장 |
|---|---|
| 앱 아이콘 | `assets/images/icon.png` (스토어용 512 별도 확인) |
| 피처 그래픽 | 1024×500 (별도 제작) |
| 폰 스크린샷 | 최소 2장, 권장 4장 이상 |

### 스크린샷 권장 컷

1. **지도** — 신분증 + 오늘의 운세
2. **사주** — 오늘의 사주 카드
3. **지인** — 궁합 점수·등급
4. **타로** — 오늘의 카드

실기기에서 캡처 후 업로드 (이 문서는 컷 목록만 고정).

## 4. 출시 전 스모크

- [ ] 신규 설치 → 프로필(신분증) 입력
- [ ] 지도·성향·사주·타로·지인 탭 진입·스크롤
- [ ] 상세 「내용 보기」해금 → 자정 전 유지 확인(가능하면)
- [ ] 지인 추가 → 궁합 상세 → 양·음력 병기
- [ ] 알림 허용 / 거부 각각 한 번씩
- [ ] 설정 → 백업 내보내기·복구(테스트 파일)
- [ ] 설정 → 개인정보·이용약관 화면 열림
- [ ] 「광고 보고」 문구가 화면에 없음

## 5. 빌드

```bash
eas build -p android --profile production --non-interactive
```

산출물: **AAB**. Play Console → 프로덕션(또는 내부/비공개 테스트)에 업로드.
